# Agent Note：小薇右侧产物预览

Status: implemented

[English](2026-08-24-xiaowei-artifact-registry.md) | 中文

## 问题

生成的 HTML 页面、Markdown 文档、幻灯片、表格和图表需要持久身份与足够大的渲染区域。在每个工具行中渲染 iframe 会使对话记录难以浏览，而 `host.openPath` 不能让远程桌面客户端显示服务器上的文件。存储的产物还必须只对创建它的账号和会话可见。

## 决策

### 持久产物服务

`@deepseek-ai/dsh-artifact` 定义 `ArtifactRegistry` 服务，以及 `html`、`slides`、`doc`、`sheet`、`chart` 五种封闭的产品类型。每个视图包含不透明的 `ArtifactId`、生产工具、媒体类型、字节数，以及可选的工作区和会话归属。

`@deepseek-ai/dsh-artifact-store-fs` 将字节存放在 `DSH_HOME/artifacts/v1/objects` 下，将 JSON 元数据存放在 `DSH_HOME/artifacts/v1/meta` 下。SHA-256 摘要就是产物 id。读取在返回数据前校验摘要和字节数。当前 RPC 信封仅支持 JSON，因此读取结果用 base64 传输字节。

### 生产工具与组装

当宿主提供 `artifactRegistry` 时，标准预设按条件挂载 `html_build`、`slides_build`、`doc_build`、`sheet_build`、`mermaid_build` 和 `svg_build`。每个工具都要求存在 Agent 会话，并在写入时记录该 `sessionId`。`doc_build` 接受 `format: 'html' | 'markdown'`；Markdown 会以原格式存储，不会先转换成 HTML。

工具成功后，将产物 id、媒体类型和字节数写入既有的持久工具结果呈现元数据。历史重放后仍可恢复卡片，无需向会话日志增加产物字节或新事件。

### 桌面呈现

产物工具行显示为紧凑卡片。点击卡片会调用类型化的 `openArtifact` owner action，在会话范围的 conversation store 中选中产物，并打开既有的可拖动详情栏。`ui-conversation` 声明 `conversation.details.artifact`，桌面端在该位置注册 `DocumentPreviewPanel`。外层详情栏只命名一次该界面，产物模式为查看器提供贴边内容区，不再嵌套另一个带边框的面板。查看器列出当前会话的产物、选中被点击的项目，并允许在其他项目之间切换。切换会话时，既有布局生命周期会关闭详情栏。

紧凑工具栏显示当前产物身份，并使用带标签的图标控件，使浏览器打开、全屏预览、下载和刷新能放入窄栏。它可以把同一个已挂载的查看器 portal 到覆盖应用框架的对话框，按 Escape 可返回详情栏。列表数量、选中行、短暂状态、预览画布和对话中的产物卡片在浅色与深色主题下都使用共享的 `--dsw-*` 主题别名。

HTML 查看器为狭详情栏提供 960 个 CSS 像素宽的隔离页面视口，再将其缩放到可用画布。这样可保留桌面式仪表盘布局，避免触发移动端断点或裁剪页面。覆盖应用框架的预览宽度达到 960 像素后直接使用可用原生宽度。

渲染器按以下方式处理媒体类型：

- HTML、幻灯片、文档、表格和 Mermaid 页面使用带 `sandbox="allow-scripts"` 的 iframe。打包后的桌面端通过独立提供的 `xiaowei-artifact:` 响应加载 frame。主进程重新执行已授权的产物读取，校验身份、媒体类型、字节数和字节后，返回带 CSP 的 HTML；该策略允许自包含脚本，同时禁止网络连接、子 frame、对象、表单、顶层导航和非 data 媒体。父渲染器保留更严格的脚本策略；浏览器开发环境使用沙箱 `srcDoc` 回退。
- Markdown 使用开启 GFM 的 `react-markdown`。不启用原始 HTML，链接不可跳转，远程图片显示为文本标签，data 图片仍可渲染。
- SVG 以图片 data URL 加载，绝不插入父页面 DOM。PNG 和 JPEG 也使用图片 data URL。PDF 使用 PDF.js。

原生文件操作仅通过 IPC 传递内容寻址的产物 id。主进程重新执行已授权的 `artifact.read`，校验返回的 id、媒体类型、字节数和 base64 负载，并自行生成文件名。下载使用操作系统另存为对话框。HTML 外部预览会注入同一套无网络 CSP，在随机的 `0700` 临时目录下以 `0600` 权限写入私有文件，再交给默认应用。桌面端会在固定有效期结束后和进程退出前删除临时预览目录。

### 账号授权

账号调用 `artifact.list` 时必须提供会话过滤条件，而且该会话必须属于调用者。`artifact.read` 和 `artifact.remove` 会先读取持久视图，再校验其中的会话归属，然后才返回或删除字节。不存在和属于其他账号的 id 都返回 `artifact-not-found`。本地调用保留既有的单用户列表、读取和幂等删除行为。

## 备选方案

- **在对话记录中渲染完整产物**——拒绝。多个浏览上下文会增加长对话的成本并遮蔽对话内容。对话记录只保留紧凑的重新打开入口，由详情栏负责渲染。
- **使用 `host.openPath`**——拒绝。远程调用会打开服务器上的路径，而不是桌面电脑上的路径；Markdown 和 HTML 也无法获得统一的产品界面。
- **把产物字节写入会话事件**——拒绝。大型不透明负载会增加日志与重放成本。持久工具输出中只保留小型引用。
- **放宽渲染器 CSP 或使用渲染器创建的 blob URL**——拒绝。嵌套文档会继承创建者或宿主渲染器的脚本限制，因此在其中允许产物内联脚本也会放宽应用界面。独立提供的预览响应使两套策略相互隔离。
- **使用仅桌面端可用的 `WebContentsView`**——暂缓。它能提供更强的进程隔离，但需要主进程视图定位和桌面专用 IPC。沙箱 iframe 可同时用于桌面和 Web 客户端；若部署需要运行不受信任的主动内容，应先增加隔离视图，再开放更广泛的能力。

## 影响

桌面端拥有一个类似 ChatGPT 的统一产物查看器，可显示生成的 HTML、Markdown、文档、表格、幻灯片、图表、图片和 PDF。它在视觉上与对话详情栏连续，同时保留并排详情、桌面布局适配、覆盖应用框架的预览、原始字节下载，以及将受限 HTML 交给默认浏览器。预览按会话过滤并按账号授权，自包含 HTML 脚本在隔离的产物策略下执行，默认禁止远程媒体。

当前文件系统布局同时使用内容摘要作为对象和元数据文件名。因此，不同会话写入完全相同的字节时会共享一条元数据；在依赖跨会话去重之前，后续存储迁移必须拆分唯一引用 id 与共享摘要。Base64 也会增加传输开销，面板当前会完整读取产物而不是流式读取。
