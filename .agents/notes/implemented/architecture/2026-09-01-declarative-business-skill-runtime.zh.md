# Agent Note: 声明式业务 Skill 运行时

Status: implemented

[English](2026-09-01-declarative-business-skill-runtime.md) | 中文

## Problem

账号 Skill 当前存储 Markdown 指令，账号插件安装则为后续 Session 选择部署方拥有的可执行 activator。两条路径都不能把新的业务 API 操作作为账号隔离配置发布，并在不重启 Host 或部署源码的情况下生效。允许定义提供可执行代码、任意端点、凭据或身份字段，会把账号隔离和网络权限交给调用方控制的数据。

## Decision

部署一个稳定的业务运行时，其中包含版本化定义服务、按账号过滤的 Skill 提供方、稳定的模型可见分发工具、必要权限传递、已批准连接提供方和不含秘密的审计。后续业务集成只发布数据 manifest；manifest 引用已批准连接，并声明闭集操作、schema、权限、只读风险和响应限制。重试与审计行为仍由平台策略控制，不成为调用方可控的 manifest 字段。

认证 principal 与持久 Session owner 仍是仅有的账号选择来源。模型和用户输入不能提供或覆盖身份、租户、角色、凭据或授权字段。运行时在分发时解析一个不可变的 active 版本，校验操作与 schema，在连接器执行前立即解析凭据，并且只记录关于决策和结果的有限元数据。连接器把 Host 派生的用户身份和操作要求的权限传给业务 API，由业务 API 执行权威的用户权限检查。

发布会在事务写入不可变版本并推进 active 指针前校验完整 manifest。提交后刷新 Skill 注册表，使下一次查询无需重新组合 Agent 即可观察到该版本。停用和回滚会改变指针；已分发调用保留其解析版本，紧急停用则阻止新的分发。

## Alternatives considered

**把每项业务集成安装为 Cordis 代码插件。** 这保留任意实现能力，但每项集成都需要部署和修改 Session 组合，因此不满足纯配置生命周期。

**为每项配置操作生成一个动态模型可见工具。** 这为每项操作提供语义化工具名，但会改变实时 Session 的工具 schema，并增加回放复杂度。一个稳定分发工具能保持请求 header 稳定；持久 Skill 目录承载配置操作指引。

**允许 manifest 包含任意 URL、header、SQL 或脚本。** 这会使配置成为执行与网络权限通道。连接与凭据引用保持单独审批，连接器实施协议专属限制。

**把小薇 Bearer 转发到业务端点。** 账号 Session token 的受众错误，并会暴露可复用登录权限。连接器使用服务凭据或在服务端解析的受众限定授权。

## Testing

认证账号可以在不重启 Host 的情况下发布、发现、执行、停用和回滚仅包含数据的业务 Skill。聚焦检查证明由 principal 派生归属、拒绝保留字段、schema 强制、必要权限传递、保留 last-good、连接器限制、持久化无秘密审计、当前 Session 目录刷新，以及所有业务 Skill 管理 RPC 仅走桌面端云 Host。桌面安装包组合还会激活业务 Skill 管理标签。[业务指标验收](../../../../docs/ops/xiaowei-business-metrics-acceptance.zh.md)记录首个生产集成相互独立的真实端点与安装态客户端证据。

## Risks

稳定分发工具刻意比逐操作语义工具更通用，因此每条执行路径都必须在 I/O 前解析账号拥有的 active 定义、校验精确操作，并传递其要求的权限。随着账号数量增长，全局 Skill 注册表失效可能产生额外工作；把它改成 owner 范围失效需要单独的注册表约定。用户拥有的 OAuth 授权凭据存储不属于首个服务凭据提供方，不能用明文配置近似实现。

## Consequences

首次部署会增加平台代码，并需要一次普通服务重启。之后受支持的业务集成通过发布配置来切换版本、停用和回滚，无需源码变更或重启。不被已批准连接器实现的协议以及自定义可执行转换不进入 manifest；它们在单独部署的业务网关运行，或者需要新增经过评审的连接提供方。

稳定工具可以命名任意已配置 Skill 和操作，因此业务 API 必须基于可信用户身份与必要权限作出授权决定。Skill 可见性与提示词指令不授予访问权。在权威成员服务能从认证服务端状态派生活跃租户前，多租户绑定保持不可用。
