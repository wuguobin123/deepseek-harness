# Business Skill

[English](README.md) | 中文

按账户隔离的数据型 Skill 定义，支持版本发布、活动版本查询、禁用和回滚。模型只看到操作说明，凭证和身份留在服务端。

## 模型体验

### 活动业务 Skill

#### 模型看到的内容

`business_skill_call` 消费方可以把活动定义的说明、操作 ID、业务输入 schema、必要权限名和只读风险标记渲染为选中的 Skill 指引。

#### Token 影响

取决于选中的活动定义；停用版本和其他账户的版本不贡献 token。

#### KV Cache 影响

发布、停用或回滚会使下一次查询的 Skill 目录失效，并可能替换后续模型上下文后缀，但不会重写当前请求。

## 已知限制与后续工作

- 多租户成员关系和写操作暂不支持，首版仅支持 R1 读操作。
