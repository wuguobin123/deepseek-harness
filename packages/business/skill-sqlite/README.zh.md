# Business Skill SQLite

[English](README.md) | 中文

SQLite 提供者保存不可变 Skill 版本，并为每个账户和 Skill 保存一个活动指针。无效发布不会改变上一活动版本。

## 模型体验

### 存储提供方

#### 模型看到的内容

没有直接内容。`ctx.businessSkill` 消费方负责加载并展示该提供方返回的版本指引。

#### Token 影响

没有直接影响；选中定义只会通过消费运行时影响 token。

#### KV Cache 影响

没有直接影响。活动指针提交变更后，变更调用方负责刷新 Skill 注册表。

## 已知限制与后续工作

- 在批准版本化迁移前，未知数据库版本会被拒绝。
