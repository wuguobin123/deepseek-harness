# @deepseek-ai/dsh-ops-workbench-anomaly

[English](README.md) | 中文

这是 ops 工作台异常检测接口的第 1 阶段骨架。此包检测会话和轮次异常，并通过 `ctx.anomalies` 公开，使工作台能够标记、分流并处理异常会话行为。

当前插件不执行任何操作；异常检测器与首个需要展示异常的场景一同落地。该场景到来时，通过 `cordis.patch.yml` 配置项挂载。

## 插件

这是一个带 `inject: ['sessions']` 的函数插件，使检测器在首个场景落地后能够读取会话状态。异常展示接入时，通过 `cordis.patch.yml` 配置项挂载。

## 配置

无。配置随首个需要展示异常的场景一同落地。

## 模型体验

无。当前骨架不注册服务、事件、提示词或工具。

#### KV Cache 影响

无。挂载该骨架不会改变请求前缀。

## 已知限制与延后工作

- **仅有骨架**：异常检测器随首个需要它们的场景一同落地。
