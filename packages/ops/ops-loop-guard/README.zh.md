# @deepseek-ai/dsh-ops-loop-guard

[English](README.md) | 中文

使用 ops 产品所需的五类循环检测扩展 `@deepseek-ai/dsh-guard-repeat-tool-reminder`：

1. **完全重复**：相同工具调用未经改变便再次执行。
2. **乒乓循环**：两个工具调用交替执行且没有进展。
3. **疲劳调用**：不论是否相同，短时间内快速重复调用。
4. **研究停滞**：执行 RAG 查询后没有下游汇总。
5. **未知能力重复**：调用未列入已注册 manifest 的能力。

骨架提供不执行任何操作的 `apply`；五个检测器随首个触发它们的场景一同落地。此包预留接口及配套 invariant，使父级提醒服务无需临时中间层即可扩展。

## 插件

这是一个带 `inject: ['repeatToolReminder']` 且没有运行时状态的函数插件。首个触发五类检测之一的场景接入时，通过 `cordis.patch.yml` 配置项挂载。

## 配置

无。配置随首个检测器一同落地。

## 模型体验

间接影响。父级 repeat-tool reminder 负责建议性警告及其渲染。

#### KV Cache 影响

当前空检测器不增加内容；未来的建议会追加在可复用请求前缀之后。

## 已知限制与延后工作

- **仅有骨架**：检测器随首个触发它们的场景一同落地。
